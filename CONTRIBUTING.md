# Contributing to Forkroom

First off, thank you for considering contributing to Forkroom!

## Code of Conduct
Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How Can I Contribute?
1. **Reporting Bugs**: Use the GitHub issue templates to submit a bug report.
2. **Suggesting Enhancements**: Submit feature requests under issues.
3. **Pull Requests**:
   - Fork the repository.
   - Install dependencies (`npm install`).
   - Create your feature branch.
   - Run unit tests to confirm stability (`npm run test --workspace=client`).
   - Submit a pull request.
