# Security Policy

## Supported Versions
Only the latest major version is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability
Please do not report security vulnerabilities via public GitHub issues. Instead, email security issues to the maintainers or report them privately using GitHub's advisory system. We will respond within 48 hours to confirm receipt and outline next steps.
