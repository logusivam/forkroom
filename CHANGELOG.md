# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-05
### Added
- Core real-time collaborative text editor using Yjs and Monaco Editor.
- Built-in multi-language simulation runner (TypeScript, JavaScript, Python, HTML, CSS, JSON).
- Multi-client cursor presence overlay tracking and room avatar badges.
- Advanced TypeScript compilation with type assertion stripping.
- Custom Python slicing parser and loop range translation helpers.
- State-managed clipboard actions on room code tags and console outputs.
- Social sharing widgets and GitHub community support modules.
